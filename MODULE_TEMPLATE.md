## Structure d'un module

```
modules/nom-du-module/
├── README.md         ← Description du module (ce fichier adapté)
├── index.js          ← Logique et rendu HTML du module
├── style.css         ← Styles spécifiques au module
└── store.js          ← Données locales + fonctions Supabase
```
